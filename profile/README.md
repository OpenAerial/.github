# OpenAerial

[中文](https://github.com/OpenAerial/.github/blob/main/profile/README.md) | [English](https://github.com/OpenAerial/.github/blob/main/profile/README.en.md)

**可复现、可扩展的空中智能开放基础设施。**

OpenAerial 致力于降低空中智能系统从搭建、开发、训练到部署的整体门槛。我们以无人机参考平台为载体，逐步开放自研机械设计、系统集成方案、软件及仿真、数据、训练与部署流程，让全球开发者、科研团队和高校能够以可负担的成本开展自主飞行研究与应用开发，并共同积累可复用的成果。

[项目与产品资料](https://github.com/Accelerate11/OpenAerial) · [OpenAerial 150](https://github.com/Accelerate11/OpenAerial/blob/main/products/openaerial-150/README.md) · [参与贡献](https://github.com/Accelerate11/OpenAerial/blob/main/CONTRIBUTING.md)

## 我们正在建设

- **从结构开始的参考平台**：自研机械结构、整机 BOM、装配文档与市售硬件集成资料。
- **贯通开发与部署的工具链**：设备接口、固件配置、机载软件与自主飞行能力。
- **支撑研究的实验流程**：仿真、数据、训练、评估与实机验证。
- **可共同维护的开放资料**：清晰的版本关系、复现入口与中英文文档。

以上为逐步建设的方向，实际内容与验证范围以产品资料为准。
