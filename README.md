# OpenAerial 组织主页

[中文](README.md) | [English](README.en.md)

本仓库维护 [OpenAerial](https://github.com/OpenAerial) 的公开组织主页。GitHub 从本仓库的 `profile/README.md` 展示主页内容。

## 文件

- [中文组织主页](profile/README.md)
- [英文组织主页](profile/README.en.md)
- [组织公开资料](organization-profile.json)：展示名称、简介和项目入口。
- [完整 Logo](profile/assets/openaerial-logo.png)
- [头像图标](profile/assets/openaerial-icon.png)

说明文档以同目录中文 `.md` 与英文 `.en.md` 成对维护。品牌文件复用现有 OpenAerial 第一版 PNG 素材；来源与许可状态见[项目品牌说明](https://github.com/Accelerate11/OpenAerial/blob/main/assets/branding/README.md)。

## 当前项目入口

产品设计、代码、BOM、仿真与验证资料维护在 [Accelerate11/OpenAerial](https://github.com/Accelerate11/OpenAerial)。首款产品为 [OpenAerial 150](https://github.com/Accelerate11/OpenAerial/tree/main/products/openaerial-150)。

## 维护

更新主页时同步维护两种语言，并保持项目状态、开放范围和链接一致。组织公开资料文件仅记录展示字段；未定义联系方式或地址。

`profile/assets/openaerial-icon.png` 可用于组织头像上传。公开资料文件不包含头像上传设置。
