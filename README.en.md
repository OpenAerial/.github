# OpenAerial organization profile

[中文](README.md) | [English](README.en.md)

This repository maintains the public profile of [OpenAerial](https://github.com/OpenAerial). GitHub displays `profile/README.md` on the organization's overview page.

## Files

- [Chinese organization profile](profile/README.md)
- [English organization profile](profile/README.en.md)
- [Public organization fields](organization-profile.json): display name, description, and project link.
- [Full logo](profile/assets/openaerial-logo.png)
- [Avatar icon](profile/assets/openaerial-icon.png)

Maintain Chinese `.md` and sibling English `.en.md` documentation together. Brand files reuse the existing first OpenAerial PNG design. See [project brand documentation](https://github.com/Accelerate11/OpenAerial/blob/main/assets/branding/README.en.md) for provenance and license status.

## Current project

Product designs, code, BOMs, simulation, and validation materials are maintained in [Accelerate11/OpenAerial](https://github.com/Accelerate11/OpenAerial). The first product is [OpenAerial 150](https://github.com/Accelerate11/OpenAerial/tree/main/products/openaerial-150).

## Maintenance

Keep both profile languages aligned on project status, open asset scope, and links. The public fields file contains display metadata only; no contact information or address has been assigned.

Use `profile/assets/openaerial-icon.png` for an organization avatar upload. The public fields file does not configure avatar uploads.
